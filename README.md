# NewssExplorer WebApp

The NewsExplorer
WebApp created to find and save articles for news lovers.
The idea is to give users features to simplify their news search and save functionalities for later reads.

## Stack

We are using for this app the latest Vite version. This we'll help us use up-to-date functions for later improvements.
